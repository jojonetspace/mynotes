analysis image\n\nPartial field descriptions\n\nField Name\n\n\t\n\nRequire\n\n\t\n\nField Description\n\n\n\n\nImages\n\n\t\n\nOptional\n\n\t\n\nThe Images property is used to upload images for this product.\n\nThe Image field in the Images property must be of the array type, with a maximum of 8 images passed into each Image field.\n\nPutting Images in the sku attribute indicates that the image is a variant image, and putting it outside indicates an SPU image.\n\n\n\n\nname\n\n\t\n\nMandatory\n\n\t\n\nProduct name.\n\nMaximum 255 characters.\n\n\n\n\nAssociatedSku\n\n\t\n\nOptional\n\n\t\n\nIn existing product,add some SKUs, this label is required for association.\n\nNote: the associated SKU must be displayed in the seller center normally\n\n\n\n\ndescription\n\n\t\n\nOptional\n\n\t\n\nMaximum 25000 characters.\n\nHTML tags are allowed.\n\nOnly Lazada image URLs are allowed, no external URLs.\n\n\n\n\nshort_description\n\n\t\n\nOptional\n\n\t\n\nOnly text.images and URLs will be automatically filtered;Short descriptions can only use <ul> <li> or <ol> <li>\n\n\n\n\nbrand\n\n\t\n\nMandatory\n\n\t\n\n\"brand\" will be deprecated please use \"brand_ id\"\n\n\n\n\nbrand_id\n\n\t\n\nMandatory\n\n\t\n\nUse the \"brand_id\" field of the GetBrandByPages API as the value\n\n\n\n\nvideo\n\n\t\n\nOptional\n\n\t\n\nAfter uploading the video, fill in the video id of the GetVideo or CompleteCreateVideo response, and the video status must be AUDIT_SUCCESS\n\n\n\n\ngift_wrapping\n\n\t\n\nOptional\n\n\t\n\nNote: Whitelist function, if you need this function please contact PSC for more information.\n\nEnum: Yes/No\n\n\n\n\nname_engravement\n\n\t\n\nOptional\n\n\t\n\nNote: Whitelist function, if you need this function please contact PSC for more information.\n\nEnum: Yes/No\n\n\n\n\npreorder_enable\n\n\t\n\nOptional\n\n\t\n\nPreOrder switch for turning on or off products.\n\nENUM: Yes/No\n\n\n\n\npreorder_days\n\n\t\n\nOptional\n\n\t\n\nWhen PreOrder is on, it is used to enter the estimated number of processing days. The maximum and minimum values will change with the seller. This range is configured by Lazada operations staff, please contact PSC if you need to change it.\n\n\n\n\ndisableAutoFillAttribute\n\n\t\n\nOptional\n\n\t\n\nWhen the field value is true, the auto-fill feature will not be enabled.\n\nWhen creating products via the Open API endpoint, an auto-fill mechanism (enabled by default) may automatically populate unused product attributes in the payload based on algorithmic recommendations.\n\nEnum: true/false(default)\n\n\n\n\nSellerSku\n\n\t\n\nMandatory\n\n\t\n\nCustomizable by the seller, unique in the same item.\n\n\n\n\nprice\n\n\t\n\nMandatory\n\n\t\n\nThe retail price of the product, which will be displayed if the \"special price\" field is not filled or expired\n\n\n\n\nspecial_price\n\n\t\n\nOptional\n\n\t\n\nThe actual sales price of the product, if the \"special_from_date\" and \"special_to_date\" fields are not filled in, then the validity time is Long Time(Permanent validity).\n\n\n\n\nspecial_from_date\n\n\t\n\nOptional\n\n\t\n\nSpecial price start time.\n\nIf this parameter is passed, then \"special_price\" is mandatory.\n\n\n\n\nspecial_to_date\n\n\t\n\nOptional\n\n\t\n\nSpecial price end time.\n\nIf this parameter is passed, then \"special_price\" is mandatory.\n\n\n\n\npackage_height\n\n\t\n\nMandatory\n\n\t\n\nMaximum two decimal places.\n\nUnit:cm\n\n\n\n\npackage_length\n\n\t\n\nMandatory\n\n\t\n\nMaximum two decimal places.\n\nUnit:cm\n\n\n\n\npackage_width\n\n\t\n\nMandatory\n\n\t\n\nMaximum two decimal places.\n\nUnit:cm\n\n\n\n\npackage_weight\n\n\t\n\nMandatory\n\n\t\n\nMaximum two decimal places.\n\nUnit:kg\n\n\n\n\npackage_content\n\n\t\n\nOptional\n\n\t\n\nPackage details\n\n\n\n\nsaleProp\n\n\t\n\nOptional\n\n\t\n\nSales attributes are divided into \"saleProp\" fields under SKU, used to distinguish sales attributes or non sales attributes\n\n\n\n\ncolor_family\n\n\t\n\nOptional\n\n\t\n\nThis is a standard variant attribute of this category, which is Optional when only one sku is created, but required when multiple sku are created.\n\nThe standard variant property is different for each category, it may be \"size\" or something else, see this document for an explanation of the \"is_sale_prop\" property.\n\nIf the current category does not have a standard variant property, please refer to this document to create a custom variant.\n\n\n\n\ncolor_thumbnail\n\n\t\n\nOptional\n\n\t\n\nVariant thumbnail tags, only available when the SKU variant is a standard sales attribute.\n\n \n\nWhat else needs to be done before This feature helps you identify the most suitable categories of your listings from Lazada's category tree\n\nb. Mis-categorized products are subject to deactivation according to Lazada's policy\n\nAPI Usage Documentation\n\n2、Get the attributes available for the target category\n\nAfter getting the category ID, use the category ID to call the GetCategoryAttributes API to get the attributes that can be filled in a category.\n\nAPI Usage Documentation\n\n3、Get the brand id (if not, ignore)\n\nCall the GetBrandByPages API to get the list of lazada brands and extract the \"brand_id\" field of the brand to be used and use it when creating the product.\n\nNote: The brand list is different from country to country.\n\n4、Upload images\n\nExternal image URLs or local images cannot be used directly when creating or updating products, please refer to this document to convert images to Lazada image URLs.\n\nAPI Usage Documentation\n\n5、Upload video (if no video, please ignore)\n\nPlease refer to this document to upload a video and get the video id.\n\nAPI Usage Documentation\n\nLazada 2022.
